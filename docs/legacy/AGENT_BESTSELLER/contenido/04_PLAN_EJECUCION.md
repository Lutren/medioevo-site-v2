## CHECKLIST DE CALIDAD POR CAPÍTULO

Cada capítulo debe tener:
- [ ] Hook inicial (primeras 200 palabras)
- [ ] Conflicto claro
- [ ] Desarrollo de personaje
- [ ] Avance de trama
- [ ] Cliffhanger o gancho final
- [ ] 2,500-3,500 palabras
- [ ] Revisado con Hemingway App

---

## CHECKLIST DE CALIDAD POR LIBRO

Cada libro debe tener:
- [ ] 27 capítulos
- [ ] 80,000-100,000 palabras
- [ ] 1 revelación mayor
- [ ] 1 pérdida irreversible
- [ ] 1 victoria temporal
- [ ] 1 pregunta nueva para siguiente libro
- [ ] 3 actos claros
- [ ] Beta leído por 3 personas

---

## RIESGOS Y MITIGACIÓN

| Riesgo | Probabilidad | Impacto | Mitigación |
|--------|--------------|---------|------------|
| Writer's block | Alta | Alto | Outline detallado, escribir fuera de orden |
| Scope creep | Media | Alto | Respetar 90K words, cortar escenas no esenciales |
| Burnout | Alta | Alto | 2,000 words/día máximo, descansar fines |
| Pérdida de datos | Baja | Crítico | Backup automático Google Docs + local |
| Feedback negativo | Media | Medio | Beta readers tempranos, iterar rápido |

## NOTAS FINALES

### Recordatorios:
- La calidad > cantidad, pero la consistencia > perfección
- 90K words es el objetivo, no exceder
- Cada libro debe funcionar independiente
- El companion es opcional pero recomendado

### Contacto de emergencia:
- Si te atascas, revisa el outline
- Si el outline no funciona, revisa los patrones de sagas
- Si los patrones fallan, vuelve al emoción central
