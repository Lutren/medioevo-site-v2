## 2. Método para cada programa (MOI científico)

No se acepta "resuelto" sin: definición formal · lema verificable · prueba o
experimento · falsificador · comparación con baseline. Patrón de conversión:

```
Idea: el cerebro ve el futuro.
Claim verificable: el sistema nervioso compensa latencia sensorial con predicción.
Mecanismo: codificación predictiva + integración temporal.
Experimento mínimo: medir error de predicción ante estímulo visual desplazado.
Falsificador: si no hay adelanto conductual medible, la hipótesis fuerte falla.
Estado: INFERENCIA.
```

brechas que **impiden** declarar AGI. Se registran como límites honestos, no como logros:

- **Brecha I — agencia autónoma / motivación interna ausente:** opera en modelo jerárquico
  dirigido (Wabi-Sabi como único punto de entrada de la intención); sin metas propias.
- Otras brechas declaradas: aprendizaje abierto continuo, generalización fuera de dominio,
  auto-modelado robusto. Todas **INCÓGNITA**.
- "AGI lograda" permanece **BLOQUEADO** como hecho (ver [[22_AUDITORIA_ELITE]]). El valor
  real es runtime cognitivo verificable local-first, no AGI demostrada.
